About THE REAL TALK

Lets your AI agent read and build in Figma Design: frames, components, styles and variables.

Version: 1.0.0

Built by Naaser, from Tacelo, tacelo.ch. Based on cursor-talk-to-figma-mcp by Sonny Lazuardi (MIT).

How to Use

  1. Start the relay: bun run socket
  2. Add the MCP server to your client
  3. Run this plugin in your file and paste the access token once. It reconnects by itself after that.
